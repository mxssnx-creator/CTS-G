ROOT CAUSE (pulse_trader.adopt_exchange_positions)
- The reconcile ran every 25 cycles, but had a blanket guard:
      if live_n == 0 and self.open: return   # "ADOPT skip empty rest"
  meant to protect against a glitchy empty REST page. Consequence: when the
  exchange was REALLY flat (all closed/liquidated externally, fills the engine
  missed), the stale-local sweep below never ran -> tracked positions lived
  forever, and openCount (len(self.open)) kept lying to the dashboard.

- Glitch guard kept but bounded: first empty read only arms a streak counter;
  the SECOND consecutive empty adopt (50 cycles apart, plus per-position
  _exchange_flat re-check for controlled positions and age>=180s guard in the
  sweep) confirms the flat exchange and the sweep drops the phantom book.
- Streak resets as soon as the book matches the exchange; API failure (non-ok
  response) still never touches the book.
- stats() now exposes "exchangeOpenCount" (real exchange position count from
  the last adopt read; -1 = not yet read) and recon{...,exchangeOpen}.

FIX (sidecar pulse_http)

  results-export payloads forward exchangeOpenCount (overall = lane sum,
