# Additional indication packs: experimental isolation

This draft moves each configured `extraIndicators` name into its own Set pack and leaves the existing `indications` vote unchanged. Existing static Trend, Breakout and other packs remain separate packs. Each added pack has its own configured Base, Exit and trailing Sets. This is a prototype, not the CTS-A-O Signal-source port: historical evidence within a pack is still pooled across symbols and directions, changing the indicator grid causes a history rebuild, and the live selector still allows only one position per symbol. Those limits prevent a claim of fully independent live strategies.

New additional-pack client IDs include a compact Set-identity digest. Recovery requires a unique matching Set and otherwise returns no Set; it supports indices beyond 9,999. Existing legacy IDs generated for additional packs may not contain that identity and must not be assumed correctly attributable. Ownership and protective orders remain unverified against the exchange. The requested maximum 3% trailing behavior is not established by this draft.

A frozen offline eight-symbol reference used 12 hours of prehistory and 12 hours forward on 17 October 2026, 09:00–21:00 UTC. Automatic holds were off and the assumed round-trip cost was 0.15%, not an observed account fee. Two existing CTS-G indicators (`donchian_break`, `rsi2_reversion`) were selected; the grid increased from 1,654 to 3,192 Sets. Across 12 hourly checkpoints, four Base Set-window observations passed (average 0.0104%, pooled in-sample PF 1.677); no Main, Real or Real Negative observation passed. The corrected bounded execution replay produced no modeled closes and no positions open at the end. There is no execution PF or evidence of a profitable candidate. Repeated Set windows are not independent samples.

Focused tests verify the existing vote is unchanged, extra names receive separate packs, grid changes and invalid hashes do not misattribute new client IDs, and restore pins match. The complete pre-identity-change regression ran 422 checks: 420 passed; two expected-old-behavior/report-hygiene checks were corrected and passed individually. The final identity revision passed 85 trader checks and focused tests, but the full suite has not been rerun on that final tree. No live connection was changed or tested.

Reproduction requires the trusted CTS-G generated cache for this exact grid; use an empty cache path with `scripts/trade_sim.py` and the overlay patch `{"histLookbackBars":720,"histLookbackAuto":false,"holdEnabled":false,"positionCostPct":0.15,"extraIndicators":["donchian_break","rsi2_reversion"]}`. Measure live performance, memory, source-specific histories and exchange execution only after the ownership and strategy work is integrated and independently verified.
