Findings, stated plainly

  • Setup: 12 symbols, 25 consecutive 3-hour windows (75h, 2026-10-03 00:00 → 10-06 03:00), each replayed with 3 hours of pre-history. All indications and ranges on, staged Base → Main → Real, Axis + Block + Normal + Trailing on, Micro on.
  • New defaults (Base 50 / Main 30 / Real 30 @ PF 1.10): −7.75 result, 6/25 positive windows, 16/75 positive hours, 1,485 entries, net −0.151% per distinct signal.
  • Old defaults (40/12/3 @ 1.20): −4.74, 5/25 windows, 12/75 hours, 892 entries, −0.123% per signal.
  • The core problem is edge, not gating. Per distinct signal over 75h: unfiltered gross +0.004% (no edge before cost); admitted −0.051% gross; after Base+Main+Real −0.075% gross. The PF gates pick slightly worse trades than no filter, because past-window PF on these 1m signals does not persist.
  • Pooled Set PF looks high because many overlapping Sets share the same trades; the per-distinct-signal numbers are the honest measure.
  • The new defaults trade ~66% more, as asked, but with no edge more orders means more cost. Changing PF floors alone cannot make this positive.
  • What could: maker (limit) execution to cut the round-trip cost, longer holding horizons where the signals have measurable drift, and conditioning signals on move size / volume surge (planned new kinds rev15, qhour).
