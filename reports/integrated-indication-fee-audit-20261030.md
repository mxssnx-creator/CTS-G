# Integrated fee, indication and replay checkpoint

This branch combines the reference simulator correction, fee/slippage accounting changes, and experimental additional-indication packs on top of the unmerged history draft. It does not include the separate x01 ownership draft or the CTS-A-O Signal-source implementation. No live connection was changed or verified.

The 12-hour prehistory/12-hour forward reference on 17 October 2026 uses eight archived symbols, 0.15% assumed round-trip cost, automatic holds off, and one modeled position per symbol. Two existing CTS-G extra indicators were selected, producing 3,192 Sets. At hourly checkpoints, Base validation averaged 0.0104% and the pooled in-sample Base PF was 1.677, over four Set-window observations; the original General, Indications and Short Range packs and the extra Donchian pack had no Base passes. The extra RSI-reversion pack had four Base observations: 0.0433% of that pack's Set-window observations, with PF 1.677. No pack passed Main, positive Real, or Real Negative at those checkpoints; no positions closed or remained open in the corrected bounded replay. There is no execution PF and no evidence of a profitable candidate. Set windows can overlap.

For a separate 72-hour-prehistory model at the same assumed cost, Base validation averaged 0.045% with in-sample PF 1.920, two modeled closes had PF 0.010, and six positions remained open; the hypothetical equal-notional closed-plus-marked PF was 0.002. These figures are not exchange results, account equity, or a guarantee of forward outcomes. See `reference-cost-window-20261030.md` and the JSON companions for the data and limits.

The fee path uses exchange-reported commissions when supplied, otherwise maker/taker rates, and a labeled estimate if neither is available. The paper budget uses selected-symbol rates and a configured slippage allowance; actual fill-price slippage is not deducted again. It remains a shared conservative budget rather than independent cost tapes for every symbol and direction, and current x01 rates and fills are unknown.

The separate indicator packs prevent extra votes from changing the original signal, and new additional-pack client IDs fail closed when their Set identity cannot be recovered uniquely. Nevertheless, pack evidence still pools symbols and directions, the live engine still has one position slot per symbol, legacy IDs need reconciliation, and grid changes rebuild history. The requested 3% trailing-from-entry/peak behavior, CTS-A-O source coordination, live protective orders and a successful x02 exchange test are not established. Do not deploy or restart x01 from this checkpoint.
